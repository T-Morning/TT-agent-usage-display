# Codex 额度宠物插件：设计与官方能力核查

日期：2026-10-30。实现边界：仅使用公开官方扩展方式，不修改应用包，不注入宿主界面。

## 已确认的目标

- 使用官方插件的会话侧面板作为显示容器（用户已接受此替代位置）；不要求原生左侧栏头像上方常驻。
- 两个圆环纵向排列，上方 5h，下方每周；圆心显示剩余百分比。
- 自定义宠物在 5h 圆环顶部活动，不遮挡数字。
- 每个圆环按各自的剩余额度独立变色，支持自定义颜色与阈值。
- 悬停显示重置时间和更新时间；支持暂停宠物动画。
- 无数据显示 --；失败保留上次数据并标注过期，不显示成 0%。

## 已确认的菜单与设置交互

- 右键点击插件内圆环或宠物区域，直接在点击位置附近弹出菜单；不是展开整块设置抽屉。
- 菜单参考用户提供的账户菜单截图：圆角面板、图标加文字、分隔线；只实现插件相关项目，不复制账号、邀请、退出登录等宿主功能。
- 菜单提供“显示宠物/隐藏宠物”和“设置…”；前者根据状态切换并立即生效，后者左键点击后打开插件内部的详细设置对话框。
- 点击菜单外或按 Esc 关闭；菜单靠近边缘时调整位置，避免超出插件可见区域。
- 设置对话框也包含宠物显示开关，以及分别针对两种额度的圆环颜色与变色阈值设置。
- 宠物默认显示。隐藏后暂停动画、移除顶部占位，额度仍正常刷新；再次显示恢复动画。显示偏好在宿主可用的持久化机制中保存，不承诺跨设备同步。
- 设置对话框可以关闭，键盘焦点进入后受约束，关闭后返回触发位置。颜色不是表达剩余额度的唯一方式，始终保留百分比与窗口标签。
- 宠物素材尚未选定，属于视觉资源依赖；验证阶段可使用明确标注的占位，不视为自定义宠物交付。

## 官方能力核查结果

### 额度数据：存在公开协议

Codex App Server 文档公开 account/rateLimits/read 和 account/rateLimits/updated。使用 usedPercent、windowDurationMins、resetsAt，优先解析 rateLimitsByLimitId。剩余百分比为 clamp(100-usedPercent,0,100)，按实际窗口长度识别 300 分钟和 10080 分钟，不能假定所有账户都存在这两种窗口。缺失窗口显示不可用。

该协议面向构建客户端的集成；它不是 MCP 插件自动获授的宿主账户 API。未来如采用本地 MCP 桥接，仍须验证运行环境、登录状态和实际连接方式，不将当前聊天的内置额度工具当作可分发插件依赖。

来源：https://learn.chatgpt.com/docs/app-server

### 目标挂载位置：未找到公开支持

Plugin Extensions 文档提供 global 入口打开插件全屏页面，thread 入口打开会话侧面板。文档没有提供在头像上方指定位置注册常驻任意组件、改变原生侧栏布局的接口。侧栏入口不等于侧栏内嵌实时组件。公开文档无法支持承诺目标位置。

来源：https://developers.openai.com/plugins/build/extensions

### 宠物与圆环：受显示容器限制

插件页面内部可设计圆环及宠物动画，但是否在当前客户端运行需实测。不得把页面内演示等同于原生头像上方常驻，不自动替换用户目标。未选定宠物素材，不生成或擅自选择最终宠物。

### 背景模块：单独保留

官方设置提供主题、颜色、字体、侧栏半透明。没有找到允许普通插件设置宿主壁纸、图片透明度或整个窗口透明度的公开接口。插件自身页面背景不满足宿主背景需求。

来源：https://learn.chatgpt.com/docs/app/settings

## 当前决策

用户已接受会话侧面板替代位置，并确认上下双圆环、顶部宠物和右键菜单方案。下一步先验证当前客户端官方 thread 入口能否加载最小插件 UI，再验证本地额度桥接。两项通过后实施完整界面；不以浏览器演示代替客户端验收。背景模块仍单独保留，未纳入本轮额度插件实现。

## 实现顺序

1. 最小官方插件注册与会话侧面板运行验证；失败时报告具体限制。
2. 通过公开 App Server 协议验证额度读取和更新；仅本地处理登录状态，不向 UI 传递凭据。
3. 双圆环、数据异常状态、阈值颜色设置。
4. 右键菜单、设置对话框、宠物显示偏好与动画启停；最终宠物使用用户选定素材。
5. 当前 Codex 中检查面板入口、真实额度、边缘菜单定位、键盘关闭、隐藏后刷新与偏好恢复。
