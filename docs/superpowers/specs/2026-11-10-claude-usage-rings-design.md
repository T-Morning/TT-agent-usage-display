# Claude Code 额度圆环

日期：2026-11-10。挂在 Claude 桌面版主窗口顶部正中，读取本机已有的 Claude Code 用量，不上传。

## 外观

两个镜片由一条鼻梁连成一副眼镜，间距比贴在一起更开。左镜片下方写 5h 和剩余百分比，右镜片下方写周和剩余百分比。每个镜片中心只有一只眼睛，两只眼睛共用注视和眨眼。镜片弧线表示剩余，环身保持粗圆。颜色按剩余额度分档：剩余不超过 20% 为红色，不超过 50% 为琥珀色，其余为绿色。悬停显示重置时间。没有数据时圆环留空，文字为 `—`。读过一次之后失败，保留上次数字并标明过期。

## 数据

本地读取 `~/Library/Application Support/Claude/plan-usage-history.json` 的最新样本。`u.fh` 是 5 小时已用百分比，`u.sd` 是每周已用百分比，`t` 是毫秒时间戳。样本超过 20 分钟记为过期。服务只监听 `127.0.0.1:39232`，响应里不包含组织标识。

## 挂载

Claude 的正式界面来自 claude.ai。安装时把预加载脚本写到应用已经会检查的 `Contents/Resources/preload/default.js`。脚本只在该文件不存在，或已经是这份环灵脚本时写入。本机 LaunchAgent 保持读取服务运行。只支持 macOS。应用更新覆盖后需要重新安装。卸载删掉带环灵标记的预加载脚本和服务。
